# hoshi — лендинг

Одностраничник приложения **hoshi** (аниме-плеер для iOS и Android, `C:\dev\AnimeApp`).
Тёмная база `#121212`, единственный акцент `#60a5fa`, системный шрифт — визуальный язык взят
из самого приложения (`app/src/ui/theme.ts`) и веб-клиента `hoshi/web-app`, но доведён до
современного уровня: полноэкранный герой с телефоном по центру, ленты постеров, прокрутка,
которая переключает экраны в макете, и максимум анимаций.

**Экраны в макете — настоящие скриншоты приложения.** Портретные сняты на iPhone 15 Pro, ландшафтные — прямо из плеера; в кадры вклеен настоящий Dynamic Island (`tools/prepare-screens.py`), потому что в исходниках он чёрный на чёрном фоне и не читается, а рисовать «похожий» остров в вёрстке оказалось нечестно по отношению к устройству. Статус-бар в вёрстке не рисуется вообще — он уже есть в кадрах.

## Быстрый старт

```bash
npm install
npm run dev          # http://localhost:5173 — разработка с горячей перезагрузкой
npm run build        # tsc --noEmit + сборка в dist/
npm run preview      # отдаёт dist/ на http://127.0.0.1:4174
```

## Стек

- **React 19 + Vite 8 + TypeScript 7**, `base: './'` — работает и с домена, и из подпапки GitHub Pages
- **Tailwind CSS 4** (`@tailwindcss/vite`), токены объявлены в `@theme` внутри `src/index.css`
- **Motion 14** (`motion/react`) — scroll-linked анимации, пружины, `AnimatePresence`
- **Lenis** — инерционная прокрутка, выключается при `prefers-reduced-motion`
- Иконки — свои инлайновые штриховые глифы в стиле Feather (`src/components/ui/Icon.tsx`):
  тот же набор, что использует приложение, и на одну зависимость меньше

## Бейджи магазинов

Ссылок на App Store и Google Play пока нет — приложение раздаётся через TestFlight, поэтому
бейджи неинтерактивные и помечены «скоро». Когда ссылки появятся, впишите их в
`src/data/copy.ts`:

```ts
appStoreUrl: 'https://apps.apple.com/app/id...',
googlePlayUrl: 'https://play.google.com/store/apps/details?id=tv.hoshi.app',
```

Бейджи сами станут обычными ссылками с `target="_blank"`.

## Доступность и производительность

Проверено Lighthouse на собранной версии: **Accessibility 100, Best Practices 100, SEO 100,
Agentic Browsing 100** — 54 проверки, ни одной проваленной. Кроме этого:

- ноль горизонтальной прокрутки на 320 / 390 / 768 / 1024 / 1440 / 1920 (проверяется в `tools/shoot-landing.mjs`);
- ноль ошибок в консоли;
- `prefers-reduced-motion` полностью отключает движение: без сплэша, без Lenis, без параллакса,
  ленты постеров стоят на месте (но их всё ещё можно тянуть), появление блоков остаётся только прозрачностью;
- скриншоты — WebP, вьюпортные (`loading="lazy"`, первый кадр предзагружается через `<link rel="preload">`);
- `<noscript>`-блок с ключевым текстом для тех, у кого выключен JS.

**Обводку фокуса убрали сознательно** (`src/index.css`): она загоралась рамкой вокруг кнопок и
мешала. Интерактив при этом всегда заметен по собственному ховеру.

## Публикация

`npm run build` кладёт готовый сайт в `dist/` — это статика без серверной части, её можно
положить на любой хостинг. Пути в сборке относительные (`base: './'`), поэтому подпапка вида
`user.github.io/app-landing/` работает без правок.

## Права

Обложки аниме — собственность правообладателей; в репозитории лежат только уменьшенные копии
для превью. Каталог и данные — Shikimori. Видео приложение не хранит.
